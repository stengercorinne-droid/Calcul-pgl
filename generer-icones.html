🎨 Générateur d'icônes PGL

Clique sur 💾 Télécharger sous chaque taille.
Les 5 fichiers vont dans le dossier du projet, à côté de index.html.

📌 Comment s'en servir

  1. Ouvre cette page dans Chrome ou Safari (Mac ou PC).
  2. Clique sur les 5 boutons 💾 Télécharger → 5 fichiers PNG dans ton dossier Téléchargements.
  3. Déplace-les dans le dossier du projet (à côté de index.html).
  4. Applique les modifications sur index.html, manifest.json et sw.js (voir la suite du message).
  5. Sur iPhone : Supprimer l'app de l'écran d'accueil → Safari → Partager → « Sur l'écran d'accueil » → la nouvelle icône apparaît.
