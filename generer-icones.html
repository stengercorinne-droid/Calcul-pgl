🎨 Générateur d'icônes PGL

Clique sur 💾 Télécharger sous chaque taille.
Puis remplace les 5 PNG existants dans le dossier du projet.

📌 Comment s'en servir

  1. Télécharge les 5 PNG (boutons verts).
  2. Écrase les anciens fichiers dans projet calories/.
  3. Bump le cache dans sw.js : pgl-v2 → pgl-v3.
  4. Sur iPhone : supprime l'app, vide le cache Safari, réinstalle.
  5. Commit : git add *.png sw.js && git commit -m "icônes v2 avec couvert vectoriel"
